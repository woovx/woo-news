# 매일 07:00(KST, 월~토) 생성 예약 작업 프롬프트

(클라우드 예약 작업 "WOO News 주식/코인 생성"의 프롬프트. 이 저장소에서 돈다. 수정할 때 이 내용을 기준으로 하고, 예약 작업 설정도 같이 고친다.)

---

WOO News 주식/코인 카드뉴스 1장의 내용을 만든다. 이 저장소의 `CLAUDE.md` 규칙을 먼저 읽고 따른다. 한국어로 쓴다.

1. 현재 시각 도구로 한국 날짜(Asia/Seoul)를 확인한다. 이하 DATE = YYYY-MM-DD.
   `posts/DATE/post.json`이 이미 있으면 아무것도 하지 않고 끝낸다.
2. WebSearch로 **오늘(한국 날짜) 보도된 기사만** 찾는다. 검색 결과에 내용이 부족하면 WebFetch로 기사 본문을 읽는다.
   - 간밤 미국 증시 마감(다우·S&P500·나스닥, 눈에 띄는 종목)
   - 원·달러 환율, 국제 유가
   - 비트코인·이더리움 시세
   - 코스피·코스닥 개장 전 전망, 오늘 주요 일정(실적 발표·지표 발표)
   - 월요일은 간밤 미국장이 없으므로 주말 코인 흐름과 이번 주 일정 위주로 쓴다.
   - 어제 이전 기사, 전날 코스피 종가 기사를 오늘 소식처럼 쓰지 않는다.
   - 숫자와 날짜는 기사 본문에서 확인한 것만 쓴다. 기사 문장을 그대로 옮기지 않고 짧게 다시 쓴다.
   - 특정 종목·코인 매수/매도 권유처럼 읽히는 표현은 쓰지 않는다.
3. `posts/DATE/post.json`을 아래 형식으로 쓴다. 기존 예시는 `posts/2026-10-21/post.json`.
   - `date`: DATE
   - `basis`: 예) "22일 오전 7시 기준"
   - `headline`: { `title`: 한 줄(약 22자 이내), `desc`: 두 줄 이내(약 40자) }
   - `items`: 2~4개, 각각 { `title`: 한 줄(약 22자 이내), `desc`: 두 줄 이내(약 40자) }. HEADLINE과 합쳐 3~5개.
   - `check`: (선택) "오늘 밤 체크 · ..." 한 줄
   - `sources`: 카드에 쓴 언론사명 목록
   - `articles`: 근거 기사 목록 [{ `press`, `title`, `url` }] 3개 이상
   - `threads`: 쓰레드 본문. 500자 이내, 해시태그 없음, 헤드라인 중심으로 짧게, 마지막 줄 "※ 투자 책임은 본인에게 있어요"
   - `instagram`: 인스타 본문. 첫 줄 "📈 WOO News | M.DD 주식/코인" → 핵심 2~3문장 → "💾 저장해두고 장 보기 전에 다시 확인하세요" / "🔔 매일 아침 WOO News 팔로우" → "⚠️ 투자 판단과 책임은 본인에게 있어요." → 해시태그 5개 이내, 마지막은 #WOONews
4. `node scripts/validate.mjs DATE`를 돌려 통과할 때까지 고친다.
   가능하면 `npm ci && npx playwright install chromium && node scripts/render.mjs DATE`로 글이 카드에 넘치지 않는지도 확인한다. 브라우저 설치가 안 되면 이 단계는 건너뛴다(GitHub Actions가 다시 검사한다). 생성된 card.html·card.jpg는 커밋하지 않는다.
5. 확인된 당일 기사가 3개 미만이거나 국내 증시 휴장일이라 쓸 소식이 부족하면, 오래된 소식으로 채우지 말고 `posts/DATE/skip` 파일에 `[자동] `으로 시작하는 이유를 한 줄로 적는다(예: `[자동] 당일 기사 2개뿐`). 07:35 복구 작업이 한 번 더 찾아보고, 그래도 부족하면 그날은 게시하지 않는다. `[자동]`이 없는 skip은 사용자가 만든 것이다.
6. `posts/DATE/` 아래 post.json(과 skip)만 커밋해 **main 브랜치에 바로 푸시**한다. 커밋 메시지: "카드 생성: DATE".
7. 최종 답변은 짧게: 넣은 소식 한 줄씩, 확인이 약했거나 건너뛴 부분.
