# 매일 07:00(KST, 월~토) 생성 예약 작업 프롬프트

(클라우드 예약 작업 "WOO News 주식/코인 생성"이 읽고 따르는 절차. 2026-10-22부터 3분야. 이 저장소에서 돈다. 규칙을 바꿀 때는 이 파일을 고친다.)

---

WOO News 카드뉴스 3장(주식/코인·연예·보험)의 내용을 만든다. 분야마다 카드 1장, 게시물도 따로 올라간다. 이 저장소의 `CLAUDE.md` 규칙을 먼저 읽고 따른다. 한국어로 쓴다.

> **문체 플러그인 예외 (2026-10-26):** 이 저장소에는 caveman(짧은 말투)·ponytail(코드 최소화) 플러그인이 켜져 있다. `post.json`의 카드 글·쓰레드·인스타 본문, `skip` 사유, 커밋 메시지에는 이 플러그인들의 말투 규칙을 적용하지 않는다. 이 문서와 `CLAUDE.md`의 규칙대로 온전한 한국어 문장으로 쓴다.

## 1. 날짜 확인
`TZ=Asia/Seoul date +%F`로 한국 날짜를 확인한다. 이하 DATE = YYYY-MM-DD.
분야 폴더는 `posts/DATE/stock/`(주식/코인), `posts/DATE/entertainment/`(연예), `posts/DATE/insurance/`(보험).
이미 `post.json`이 있는 분야는 건너뛴다. 셋 다 있으면 아무것도 하지 않고 끝낸다.

## 2. 공통 규칙
- WebSearch로 **오늘(한국 날짜) 보도된 기사만** 찾는다. 검색 결과에 내용이 부족하면 WebFetch로 기사 본문을 읽는다.
- 어제 이전 기사를 오늘 소식처럼 쓰지 않는다. 숫자와 날짜는 기사 본문에서 확인한 것만 쓴다. 기사 문장을 그대로 옮기지 않고 짧게 다시 쓴다.
- 후킹이 되는 헤드라인(숫자·대비·질문형)을 쓰되 과장하지 않는다.
- 분야마다 기사 3~5개(HEADLINE 1 + 번호 카드 2~4).

## 3. 분야별 내용
**주식/코인 (stock)**
- 간밤 미국 증시 마감(다우·S&P500·나스닥, 눈에 띄는 종목), 원·달러 환율, 국제 유가, 비트코인·이더리움 시세, 코스피·코스닥 개장 전 전망과 오늘 일정.
- 월요일은 간밤 미국장이 없으므로 주말 코인 흐름과 이번 주 일정 위주. 전날 코스피 종가 기사를 오늘 소식처럼 쓰지 않는다.
- 특정 종목·코인 매수/매도 권유처럼 읽히는 표현 금지.

**연예 (entertainment)**
- 흥행·박스오피스·시청률·컴백·음원 차트·작품(드라마·영화·예능) 소식 위주.
- **열애·결혼·이혼·사생활·루머·사건사고, 출처 불분명한 소식은 쓰지 않는다(찌라시 금지).**

- 찾는 곳: 박스오피스(전날 영진위 집계를 오늘 보도), 시청률(전날 방송분), 음원 차트(뮤직100 등), 오늘 발매·컴백.

**보험 (insurance)**
- 찾는 곳: 보험 전문지 기사 목록(보험매일 https://www.fins.co.kr/ , 한국보험신문 https://www.insnews.co.kr/news/articleList.html , 보험저널 https://insjournal.co.kr/ )과 경제지 보험면. 특정 회사 홍보성 기사(우리 회사 서비스가 업계 1위 등)는 피한다.
- 금융당국(금융위·금감원) 발표, 보험료·제도·약관 변경, 실손·자동차·건강보험 소식, 보험사 실적·업계 동향, 소비자 유의사항.
- **특정 상품·회사 가입 권유나 판촉처럼 읽히는 내용, 보장·수익을 단정하는 표현 금지.** "확인해 보세요" 톤.

## 4. post.json 형식 (분야마다 하나)
예시: `posts/2026-10-21/stock/post.json`, `posts/2026-10-21/entertainment/post.json`, `posts/2026-10-21/insurance/post.json`
- `date`: DATE
- `basis`: 예) "22일 오전 7시 기준"
- `headline`: { `title`: 한 줄(약 20자 이내), `desc`: 두 줄 이내(약 40자) }
- `items`: 2~4개, 각각 { `title`: 한 줄(약 20자 이내), `desc`: 두 줄 이내(약 40자) }
- `check`: (선택) "오늘 밤 체크 · ..." 같은 한 줄. 보험은 카드에 안내 문구가 자동으로 붙으므로 넣지 않는다.
- `sources`: 카드에 쓴 언론사명 목록
- `articles`: 근거 기사 [{ `press`, `title`, `url` }] 3개 이상
- `threads`: 쓰레드 본문. 500자 이내, **해시태그 없음**, 헤드라인 중심으로 짧게.
- `instagram`: 인스타 본문. **해시태그 5개 이내, 마지막은 #WOONews**. 2,200자 이내.

본문 형식 (예시는 `docs/captions-2026-10-21.md`):
| 분야 | 인스타 첫 줄 | 꼭 넣을 문구 |
|---|---|---|
| stock | `📈 WOO News | M.DD 주식/코인` | 인스타 "⚠️ 투자 판단과 책임은 본인에게 있어요.", 쓰레드 마지막 줄 "※ 투자 책임은 본인에게 있어요" |
| entertainment | `🎬 WOO News | M.DD 연예` | 없음 |
| insurance | `🛡️ WOO News | M.DD 보험` | 인스타·쓰레드 모두 "가입·변경 전 약관과 설계사 설명을 꼭 확인하세요" |

인스타 순서: 첫 줄 → 핵심 2~3문장 → 저장 유도(💾) / "🔔 매일 아침 WOO News 팔로우" → (주식·보험) 책임/확인 문구 → 해시태그.

## 5. 검사
`node scripts/validate.mjs DATE`를 돌려 모든 분야가 통과할 때까지 고친다.
가능하면 `npm ci && npx playwright install chromium && node scripts/render.mjs DATE`로 글이 카드에 넘치지 않는지도 확인한다. 브라우저 설치가 안 되면 건너뛴다(GitHub Actions가 다시 검사한다). 생성된 card.html·card.jpg는 커밋하지 않는다.

## 6. 기사가 부족할 때
확인된 당일 기사가 3개 미만인 분야는 오래된 소식으로 채우지 말고, 그 분야 폴더에 `skip` 파일을 만들어 `[자동] `으로 시작하는 이유를 한 줄로 적는다(예: `posts/DATE/insurance/skip` ← `[자동] 당일 보험 기사 2개뿐`). 07:35 복구 작업이 한 번 더 찾아본다. 기사가 없어서가 아니라 WebFetch가 `ENOTFOUND` 같은 접속 오류로 안 열려서 확인을 못 한 경우에는 이유에 "클라우드 환경 네트워크 차단"이라고 분명히 적는다(2026-10-23에 이 문제로 연예·보험이 빠졌고, 환경 네트워크를 "전체"로 바꿨다). `[자동]`이 없는 skip은 사용자가 만든 것이다. 다른 분야는 그대로 만든다.

## 7. 커밋
`posts/DATE/` 아래 post.json(과 skip)만 커밋해 **main 브랜치에 바로 푸시**한다. 커밋 메시지: "카드 생성: DATE".

## 8. 최종 답변
